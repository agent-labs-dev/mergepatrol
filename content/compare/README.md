# Comparison pages

Each `.md` file here is a page at `https://mergepatrol.ai/compare/<file name>`, listed on
`/compare`. They render with the blog's template (`crates/web/src/blog.rs`) and take the same
header (`title`, `description`, `date`, optional `updated`): see [`content/blog/README.md`](../blog/README.md).

A comparison page is for someone choosing a merge queue. Keep it fair and checkable:

- Cite the other product's own docs or pricing page for every claim about it, and date the page.
  Prices and plans change: set `updated` when you re-check them.
- Say where the other product is the better fit.
- Claims about Mergepatrol must match the [README](../../README.md).
