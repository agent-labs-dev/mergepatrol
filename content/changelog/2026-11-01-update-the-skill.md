---
title: Update a repo's agent skill from Repos
kind: improved
---

Setup adds Mergepatrol's agent skill to a repo once, so a repo set up before the skill changed keeps its old copy. **Repos** now shows whether each repo's skill is up to date. If it isn't, **Update skill** opens a PR that brings it up to date, and coding agents in the repo follow the new skill once that PR merges.
