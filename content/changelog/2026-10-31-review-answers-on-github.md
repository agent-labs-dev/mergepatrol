---
title: Approving a PR on GitHub answers the agent's review
kind: improved
---

When the agent's review asks a human about a PR, an approval on GitHub from someone who can push to the repo now counts as an answer: everything the review asked about is fine, and the PR moves on in the queue. A comment on GitHub can't answer the review's questions, so the first one while the review waits gets a reply on the PR saying where to answer.
