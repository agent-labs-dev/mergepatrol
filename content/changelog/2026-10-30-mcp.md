---
title: Coding agents can queue PRs over MCP
date: 2026-10-30
kind: new
pr: 130
---

Connect Claude Code, Codex or any MCP client to `https://mergepatrol.ai/mcp` and your agent can
queue a PR, take it out, and ask where it is, without adding labels and reading Mergepatrol's
comment. It signs in with your GitHub account.

```bash
claude mcp add --transport http mergepatrol https://mergepatrol.ai/mcp
```
