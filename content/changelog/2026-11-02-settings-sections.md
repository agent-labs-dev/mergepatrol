**Settings** has a menu of its sections, and each section shows a short description beside its controls instead of a paragraph above them. It now uses the width of a wide screen.

Each API key and the ChatGPT sign-in are one row each. Under **Automatic review**, every kind of finding has its own row with its chart and slider, so you can see and set all of them at once.
